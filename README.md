#  Top 10 Products by Sales

## Veda Technology – Data Analytics Internship

### Objective
Identify the top 10 products based on total sales using ranking and sorting techniques.

### Tools Used
- Microsoft Excel
- Python
- Pandas
- Data Visualization

### Project Deliverables
1. Top 10 products sales ranking table.
2. Horizontal bar chart showing product sales.
3. Product-wise sales summary.
4. Raw dataset containing 2,000 records.
5. Project methodology and documentation.

### Methodology
- Grouped transactions by product.
- Calculated total sales, units sold, and total profit.
- Sorted products in descending order of total sales.
- Assigned sales ranks.
- Visualized the top 10 products using a bar chart.

### Files Included
- `Task_19_Top_10_Products_by_Sales.xlsx`
- `Superstore_Practice_Raw_Data.csv`

### Dataset Note
The dataset is synthetic practice data created for this project because the original Superstore dataset was not supplied.

### Outcome
Successfully created a ranked top 10 products report with supporting data and visualization.
